# God-AI-Diet-Coach 🥗

An AI-powered personalized vegetarian diet coach that generates healthy diet plans based on age, height, weight, and fitness goals.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **AI Integration:** Gemini AI

## 🚀 Features
- Personalized meal recommendations
- Automated calorie tracking based on goals
- Simple and interactive user interface

## 📦 How to Run Locally
1. Clone the repository
2. Install dependencies: pip install -r requirements.txt
3. Run the app: streamlit run app.py
